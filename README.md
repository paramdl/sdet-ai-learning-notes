# SDET + AI Quality Engineering Notes

Study notes and a structured plan for moving from test automation into AI quality engineering.

| Folder | What's inside |
|---|---|
| [`sdet-ai-roadmap/`](sdet-ai-roadmap) | 13-week plan: TypeScript + Playwright (core, OOP with real Playwright examples, commands, 40 practice programs, interview Q&A), DevOps (Git, Docker, Jenkins, Kubernetes at interview level), an LLM slice (Python for LLM testing, theory, evaluation, interview Q&A) and a capstone project brief |
| [`genai-testing-handbook/`](genai-testing-handbook) | A 31-part handbook on testing generative AI: LLM fundamentals, prompt engineering, API testing, evaluation (LLM-as-judge, golden datasets), RAG and vector DB testing, agents, multimodal, AI security and red-teaming, guardrails, performance, cost, observability, CI/CD, governance, plus a test-case library, cheat sheets and labs (DeepEval, promptfoo) |

`md2pdf.py` / `build_pdf.py` render the Markdown to PDF (reportlab, no pandoc needed).
